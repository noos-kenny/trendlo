# # Trendlo — NOOS knowledge tree

Client knowledge base maintained by NOOS. Skills and agents read from and
commit to this repository.

## Where things live

| Path | What |
|---|---|
| `_claude-data/` | Meta: field status, logbook, working instructions, version stamp, production runbook |
| `Info/` | Client facts, brand, customer voice |
| `Strategy/` | Marketing and creative strategy, measurement, hypothesis ledger |
| `Audits/` `Scrapes/` `Reports/` | Dated snapshots — read, never edited |
| `Upload/` `Client-feedback/` `_internal-feedback/` | Dated source material and feedback |
| `_noos-creativeintelligence/` | Read-only mirror of NOOS methodology — never edit |

## Before you change anything

Read `_claude-data/workinginstructions.md`. It is the source of truth for
naming, language and the update routine.

Start here: `_claude-data/client-data-overview.md` shows what has been
collected and what is missing.
