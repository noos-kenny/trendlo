# Template — Creative Brief (asset order)

The full NOOS brief format (design rules, card structure, .docx output) lives in the `nooscreativebrief` skill — use that for client-facing briefs. This template is the minimum content a production brief must carry so the test stays traceable.

```
CREATIVE BRIEF — [client] — [yyyy-mm-dd]
─────────────────────────────────────
Hypothesis: [H-YYYY-Q-###]
Persona: [name + one-line motive]
Trigger: [primary, one of the 12]
Objection answered: [buyer's own language]

HOOK
  [Verbatim — the first 1–3 seconds / first line]

ANGLE
  [How the trigger is expressed in this asset]

FORMAT & TECHNIQUE
  [9x16 video, split-screen / static / carousel ...]

MUST INCLUDE
  [Proof elements, product, offer, CTA, guardrails]

MUST AVOID
  [Anti-patterns for this brand/market — see method/10_anti_patterns.md]

AD NAME (primary)
  fmt:...-foc:...-pers:...-bar:...-trig:...-con:...-h:...-tmpl:...-br:...-p:...-lp:...-v:...-d:YYMMDD
  (per testing/naming_conventions.md — empty attributes are skipped)
```
