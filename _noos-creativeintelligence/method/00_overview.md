# NOOS Creative Intelligence System — Knowledge Base

A modular knowledge base for performance creative work at NOOS. The base codifies our methodology and grounds it in consumer psychology, behavioural economics, and Nordic cultural context.

Use this as a reference for any project that involves creative strategy, hypothesis design, paid social, or campaign planning across consumer and business brands.

## How to use the knowledge base

Three primary use cases:

1. **As context for AI assistants.** Load the relevant module(s) into a system prompt or project context. Start from the repo `README.md`, which maps `method/`, `testing/` and `learnings/`.
2. **As an internal reference for strategists and creatives.** Each module is self-contained. Read top-down or jump straight to the section you need.
3. **As a client-facing artefact (with light editing).** Most modules are written in a tone that can be shared with sophisticated clients after stripping internal notes.

## Conventions

- **Language:** English. Nordic-specific terminology is translated and explained.
- **Markets in scope:** Sweden, Norway, Denmark, Finland. Other markets are referenced only where contrast is useful.
- **Vertical scope:** Performance creative across e-commerce (apparel, beauty, home, food, supplements), D2C subscription, B2B lead generation (SaaS, services, financial), B2C lead generation (insurance, education, home services), and B2B SaaS. Vertical-specific adaptations live in `06_vertical_adaptations.md`.
- **Price tier:** The framework applies across mass, mid-tier and premium positioning. "Premium" is treated as one of several positioning choices, not as the default.
- **Updates:** Treat each file as living. Date material changes at the bottom of the file.
- **Citations:** Academic sources are named inline (author + year). Where a claim is operational rather than academic, it is marked *practice*.
